# Quoth (macOS menu-bar dictation)

Quoth is local voice transcription for the Mac. Hold `fn` (or another
modifier), speak, release, and the transcript is pasted at the cursor; a
double tap locks recording on for hands-free dictation, with text typed at
each pause. Whisper runs on-device through WhisperKit (CoreML, Apple Neural
Engine). macOS 14+, Apple silicon only. No account, no analytics, no server.

## Two editions from one codebase (ADR-006)

| | Direct edition | App Store edition |
|---|---|---|
| Built from | `Package.swift` (SwiftPM) | `project.yml` (XcodeGen → `Quoth.xcodeproj`) |
| Bundle ID | `com.victorshammas.quoth.direct` | `com.victorshammas.quoth` |
| Price, channel | free, GitHub releases (notarized DMG) | $1.99, Mac App Store |
| Sandbox | no (hardened runtime) | yes |
| Hotkey | a modifier key (fn), under Accessibility | a key combination (⌥Space), no grant (ADR-008) |
| Paste at cursor | covered by Accessibility | its own optional grant; else copy for ⌘V |
| Reads the focused field | yes | no (compiled out; `scripts/appstore.sh` fails if any `_AX*` symbol is linked) |
| Updates | Sparkle, from GitHub releases | App Store |
| Entry point | `Sources/quoth/main.swift` | `AppStore/main.swift` |

Both editions use team `JPP8RN6BJB`. Everything that differs is decided in
`Sources/QuothPlatform/Support/Edition.swift` (`Edition`, `HotkeyAccess`,
`PasteAccess`); only those test the `APPSTORE` flag. `project.yml` leaves
`Sources/QuothCore/App/Updater.swift` (Sparkle) out of the App Store build.

## Layout

Read `docs/architecture.md` first: it is the target structure and says where
each kind of change belongs. Decisions are in `docs/decisions/` (ADR-001 to
ADR-008).

- `Sources/QuothDomain/` — pure logic, Foundation only: `DictationMachine`
  (the loop's decisions), gestures, dictionary, voice commands, settings
  values, the model catalog (`Transcription/ModelRegistry.swift`).
- `Sources/QuothPlatform/` — macOS behind small types: audio capture (AUHAL),
  the hotkey event tap, text insertion and clipboard, focus, permissions,
  `Paths`, `Edition`.
- `Sources/QuothSpeech/` — WhisperKit: transcriber, tuning, language
  detection, model files on disk.
- `Sources/QuothCore/` — the app: `App/` (AppModel, DictationSession,
  onboarding, startup, Updater), `UI/` (menu bar, pill, Quote Card, Settings
  panes), `Dictionary/`, `Settings/`.
- `Sources/quoth/` — the direct edition's executable (one call into QuothCore).
- `Sources/quoth-bench/` — transcription benchmark, never shipped.
- `Tests/QuothTests/`, `Tests/QuothBenchTests/` — XCTest.
- `AppStore/` — App Store target: `Info.plist`, `Quoth.entitlements`,
  `Quoth.xcconfig` (version, build number, team), `ExportOptions.plist`,
  `PrivacyInfo.xcprivacy`, `Assets.xcassets`, `screenshots/` (+ `compose.swift`).
- `packaging/` — direct edition: `Info.plist` (Sparkle feed and public key),
  `Quoth.entitlements`, `AppIcon.icns`.
- `scripts/` — build, install, App Store, DMG, release, icon and
  acknowledgements generators (below).
- `docs/` — the public website (GitHub Pages) plus developer docs.
- `.github/workflows/ci.yml` — CI.

Modules depend one way: QuothDomain ← QuothPlatform ← QuothSpeech ← QuothCore.
QuothCore types the benchmark needs are `package`; the App Store target
compiles with `-package-name quoth` for that reason.

## Build and run

Direct edition (Swift package):

    swift build -c release && swift test
    scripts/dev-install.sh        # build, sign, install Quoth.app, reopen a running copy

`scripts/dev-install.sh` installs to `/Applications` (or `~/Applications`)
and takes `QUOTH_SIGN_IDENTITY`, `QUOTH_INSTALL_DIR`, `QUOTH_NO_RESTART=1`.
It calls `scripts/build-app.sh [version]`, which writes `build/Quoth.app`,
embeds and signs Sparkle, and signs with the first Developer ID Application
identity, else Apple Development, else ad hoc (with a warning).

Run with optional developer variables
(`Sources/QuothCore/Support/DeveloperOptions.swift`) through `open`, with
any running copy quit first, and follow the log:

    open -a Quoth --env QUOTH_DUMP_WAV=1
    tail -f ~/Library/Logs/quoth/quoth.err.log

Not `QUOTH_DUMP_WAV=1 /Applications/Quoth.app/Contents/MacOS/quoth`: macOS
then checks the terminal's privacy grants, not Quoth's, and the microphone
is refused. Away from a terminal, stdout and stderr go to `~/Library/Logs/quoth/`.

`QUOTH_DEBUG_HOTKEY=1` logs modifier changes; `QUOTH_INJECT_MODE=type-unicode`
types instead of pasting. There is no command line (ADR-007).

App Store edition (needs `brew install xcodegen`):

    xcodegen && open Quoth.xcodeproj
    scripts/appstore.sh build     # build/appstore/Build/Products/Release/Quoth.app

`Quoth.xcodeproj` is generated and gitignored; edit `project.yml`, never the
project. The `build` step re-signs as Apple Development when that
certificate is present, so grants survive rebuilds.

Benchmark:

    swift run -c release quoth-bench <folder of .wav recordings>

## Tests

- `swift test` runs `QuothTests` and `QuothBenchTests` (direct edition).
- CI (`.github/workflows/ci.yml`, `macos-latest`, every push and pull
  request): `swift test`, then `brew install xcodegen` and
  `scripts/appstore.sh build`. The App Store edition is built, not tested.
- `ScreenshotRenderTests` skip unless `QUOTH_RENDER_DIR` is set; they render
  the App Store screenshots (see RELEASING.md).
- Pure logic gets unit tests (architecture rule 5).

## Signing, sandbox, entitlements

- macOS keys the Microphone and Accessibility grants to the
  code identity. Always sign with a stable identity; an ad-hoc build loses
  its grants on the next rebuild (ADR-005). Changing a bundle ID, signing
  team, or the Sparkle key breaks grants or updates for existing users.
- Direct: `packaging/Quoth.entitlements` (audio input only), hardened
  runtime, Developer ID + notarization for releases.
- App Store: `AppStore/Quoth.entitlements` — app sandbox, audio input,
  network client (model downloads only). Xcode automatic signing.
- Secrets never go in the repo: Developer ID certificate, the notarytool
  profile `quoth-notary`, Quoth's Sparkle EdDSA private key (keychain; public
  half is `SUPublicEDKey` in `packaging/Info.plist`), the App Store Connect
  API key (`~/.appstoreconnect/private_keys/AuthKey_<ID>.p8`). `release/` is
  gitignored for keys and exports.
- The Sparkle private key is on the author's M5 Pro MacBook; run direct
  releases (`scripts/release.sh`) there (see `RELEASING.md`).

## Models and data on disk

- Models download on first start from Hugging Face
  (`argmaxinc/whisperkit-coreml`) into
  `~/Library/Application Support/quoth/models/`. Default `whisper-base.en`
  (145 MB); others in `Sources/QuothDomain/Transcription/ModelRegistry.swift`.
  The App Store build's network entitlement exists only for this.
- Settings and dictionary: `~/.config/quoth/settings.json` and
  `~/.config/quoth/dictionary` (plain-text table; `docs/dictionary.md`).
  Logs in `~/Library/Logs/quoth/`. In the sandbox these land in the
  container. Every path comes from `Sources/QuothPlatform/Support/Paths.swift`.
- Transcript text is never written to logs or disk (architecture rule 1).

## Distribution

- **Direct / GitHub releases:** `scripts/release.sh <version> [notes.md]`
  runs `scripts/make-dmg.sh` (build, notarize, staple, DMG, update zip),
  writes and signs the Sparkle appcast, tags `vX.Y.Z`, pushes the tag and
  creates the GitHub release with `Quoth-X.Y.Z.dmg`, `Quoth.dmg` (fixed name
  for the website's download link), `.dmg.sha256`, `Quoth-X.Y.Z.zip` and
  `appcast.xml`. Installed copies update from
  `releases/latest/download/appcast.xml`.
- **Mac App Store:** `scripts/appstore.sh archive` then `upload`, with
  `ASC_KEY_ID` / `ASC_ISSUER_ID` (and optionally `ASC_KEY_PATH`). Version and
  build number in `AppStore/Quoth.xcconfig`. Listing text and review notes
  are kept local and gitignored (`AppStore/metadata.md`,
  `AppStore/review-notes.md`); screenshots are committed in
  `AppStore/screenshots/`.
- Full checklist: `RELEASING.md`. History: `CHANGELOG.md`.

## Generated files

- `Sources/QuothCore/UI/AcknowledgementsText.swift` — from
  `swift package resolve && python3 scripts/make-acknowledgements.py`. Rerun
  when a dependency changes.
- Icons — `swift scripts/make-quoth-icon.swift` writes
  `packaging/AppIcon.icns`, `AppStore/Assets.xcassets` and

  (commands in `docs/SITE.md`).

(`argmax-oss-swift`) 1.1.0 and swift-argument-parser 1.7.1 are pinned with

together.

## Conventions

- The rules in `docs/architecture.md` §8: no transcript text on disk or in
  logs; every path from `Paths`; every preference through `SettingsStore`
  (no `UserDefaults` beyond Sparkle's); new post-transcription behaviour is
  a `TranscriptProcessor` or `DictationObserver`; the event tap listens to
  `flagsChanged` only, and the App Store edition has no tap at all (ADR-008);
  pre-permission buttons say Continue, never Allow (App Review 5.1.1(iv));
  no OpenAI or ChatGPT in App Store metadata (App Review 5); only
  `Edition`/`HotkeyAccess`/`PasteAccess` test
  `APPSTORE`. Every feature must work in, or degrade to, the clipboard-only
  App Store build.
- Commit subjects: `Area: what changed, in plain words` (e.g. "Delivery:
  notice when nothing takes the paste"), with a body explaining why for
  behaviour changes. Parrot-era commits used lowercase prefixes.
- Docs carry a `Last updated: \`YYYY.MM.DD\`` line; record significant
  decisions as a new ADR in `docs/decisions/`.
- Plain, concrete, unhyped prose in UI, README, site and release notes; no
  emoji.
- Local-only, gitignored: `.plan/` (planning notes), `release/`,
  `AppStore/metadata.md`, `AppStore/review-notes.md`. They do not travel
  between Macs through git.
- Contact: contact+quoth@victorshammas.com.
- Releases: follow `RELEASING.md` and add an entry to `CHANGELOG.md`.
